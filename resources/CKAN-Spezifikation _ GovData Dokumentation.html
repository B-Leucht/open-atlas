CKAN-Spezifikation

Für das Datenmanagement bei GovData wird ein CKAN-System eingesetzt. Über die CKAN-API können die Metadaten abgerufen werden. Folgend wird die Spezifikation als OpenAPI bereitgestellt (die Ursprungsversion hat data.gv.at erarbeitet). Ihr könnt alle Endpunkte direkt auf dieser Seite ausprobieren.

Die aktuelle Version kann hier im OpenAPI Format heruntergeladen werden.
